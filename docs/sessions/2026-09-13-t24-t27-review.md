## 3. Findings

### F-1 D2 implemented with inverted semantics (T-24) — blocking

Spec (`docs/requirements.md` §32-1 D2, v2 note §5 T-24 prompt): strip blockquotes, slide
200-char windows over the **remaining body**, WARN when the body is **≥ 0.85 similar** to
the source (= verbatim copying, §17-1 ①主従).

Code (`scripts/content_audit.py` L88–L102 at `5012356`): iterates `quotes =
BLOCKQUOTE_RE.findall(content)` and appends `WARN:VERBATIM_COPY` when the **blockquote**
text is **< 0.85** similar to the source. That is §32-1 **D7** (⑤改変禁止, explicitly
deferred), under the D2 label. `tests/test_content_audit.py` L44–L65 asserts the inverted
behaviour, so the suite was green while the spec row was wrong. The same commit flipped
the D2 row to 実装済み.

Decision (spec owner): keep the shipped check as D7 under the honest name
`WARN:QUOTE_ALTERED:<ratio>` (WARN-only satisfies the §32-2 false-positive mitigation that
justified deferring D7), and implement the real D2. Spec rows D2/D7 and §17-1 ⑤ updated in
the same docs commit as this note.

### F-2 D5 lookup covers FAIL rows only (T-24) — minor, same round

`find_rejected_fact()` filters `verdict = 'FAIL'`. UNVERIFIABLE content is also stored in
`facts`, so resubmitting it writes a second row. Linux measurement: same UNVERIFIABLE
content posted twice → `facts` 3 rows / 2 distinct hashes (`fact_id` 2 then 3). The ratchet
only aggregates FAIL rows (`ratchet_check.py` L56), so this does not corrupt proposals, but
it violates the "no duplicate facts row for the same hash" clause. Fix: `verdict != 'PASS'`.

### F-3 image overrides a PaaS `PORT` (T-26) — blocking for T-12, orchestrator error

`Dockerfile` sets `ENV AINAVI_GATE_PORT=8090`; `main()` resolves `AINAVI_GATE_PORT`
before `PORT`, so a Render/Fly-injected `PORT` is ignored. Linux measurement with the
image's env: `AINAVI_GATE_PORT=8090 PORT=10000` → `/health` on 8090 → 200, on 10000 →
no listener. With `PORT=10001` only → 200 on 10001, so the resolution order itself is
right; the baked ENV is the defect. **The T-26 prompt in the v2 note specified that ENV
line**, so this is my error, not an implementer deviation → CLAUDE.md §C-4.

### F-4 skill doc drift (docs, fixed here)
