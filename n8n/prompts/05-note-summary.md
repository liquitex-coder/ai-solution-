# ワークフロー05: note 記事紹介プロンプト

## 入力変数

| 変数 | 内容 |
|---|---|
| `{{ $json.title }}` | note 記事タイトル |
| `{{ $json.creator }}` | 著者名 |
| `{{ $json.link }}` | note 記事 URL |
| `{{ $json.summary }}` | 記事概要（RSS contentSnippet） |

## プロンプト本文

```
あなたはAI情報専門サイト「AIナビ」のライターです。
以下のnote記事を参考に、AIツールの使い方や実践知識をまとめた紹介記事を書いてください。

【注意事項】
- 元記事を転載・丸ごとコピーしないこと（著作権保護のため要約・紹介にとどめる）
- 元記事へのリンクを必ず含めること
- 概要から読み取れる内容を基に編集し、推測部分は明示すること

【出力フォーマット】
1行目は必ず <h2> タグで始めること。HTMLページ構造タグは禁止。

元記事情報:
- タイトル: {{ $json.title }}
- 著者: {{ $json.creator }}
- URL: {{ $json.link }}
- 概要: {{ $json.summary }}

以下の構成でHTMLとして記事を作成してください:

<h2>この記事で学べること</h2>
<ul>
<li>[要点1]</li>
<li>[要点2]</li>
<li>[要点3]</li>
</ul>

<h2>注目のAI活用アイデア</h2>
<p>[元記事から読み取れる実践的な活用方法を具体的に解説]</p>

<h2>初心者が今日から試せるステップ</h2>
<ol>
<li>[ステップ1: 最も簡単なこと]</li>
<li>[ステップ2: 次の一手]</li>
<li>[ステップ3: 応用]</li>
</ol>

<h2>著者 {{ $json.creator }} について</h2>
<p>[著者名と記事のトーンから、専門性を1文で紹介]</p>

<p>📝 <strong>元記事を読む（無料）</strong>:
  <a href="{{ $json.link }}">{{ $json.title }}</a>（by {{ $json.creator }}）
</p>

日本語で、実際に試せる内容を重視して書いてください。
```

## 使用モデル

`claude-haiku-4-5-20251001`

## max_tokens

`2000`
