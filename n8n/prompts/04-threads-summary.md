# ワークフロー04: Threads インフルエンサー投稿まとめプロンプト

## 入力変数

| 変数 | 内容 |
|---|---|
| `{{ $json.username }}` | Threads ユーザー名 |
| `{{ $json.postCount }}` | AI関連投稿数 |
| `{{ $json.postsText }}` | 投稿内容（各投稿をリスト形式で連結） |

## プロンプト本文

```
あなたはAI情報専門サイト「AIナビ」のライターです。
以下のThreadsのAIインフルエンサーの投稿をまとめた「AIノウハウまとめ」記事を書いてください。

【出力フォーマット】
1行目は必ず <h2> タグで始めること。HTMLページ構造タグは禁止。

アカウント: @{{ $json.username }}
AI関連投稿数: {{ $json.postCount }}件

投稿内容:
{{ $json.postsText }}

以下の構成でHTMLとして記事を作成してください:

<h2>今週の注目AIノウハウ（@{{ $json.username }} まとめ）</h2>
<p>[インフルエンサーの専門性と今回の投稿の総評を2〜3文]</p>

<h2>実践的なTips まとめ</h2>
<ul>
[各投稿から実践的なヒントを抽出。投稿URLへのリンクを含める]
</ul>

<h2>あなたの業務に活かすには</h2>
<p>[ビジネスパーソン・AI初心者向けに、今日から試せる活用方法を2〜3つ提案]</p>

<h2>注目の投稿</h2>
[最も重要・反響が大きそうな投稿を1〜2件ピックアップ。引用と解説付き]

<p>📱 フォローして最新情報をチェック:
  <a href="https://www.threads.net/@{{ $json.username }}">@{{ $json.username }}</a>
</p>

日本語で、AI初心者にも実践しやすい内容を重視して書いてください。
誇張せず、投稿内容に忠実に編集してください。
```

## 使用モデル

`claude-haiku-4-5-20251001`

## max_tokens

`2000`
