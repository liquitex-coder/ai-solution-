# ワークフロー03: YouTube 動画紹介記事プロンプト

## 入力変数

| 変数 | 内容 |
|---|---|
| `{{ $json.title }}` | 動画タイトル |
| `{{ $json.channelTitle }}` | チャンネル名 |
| `{{ $json.publishedAt }}` | 公開日時 |
| `{{ $json.description }}` | 動画説明文 |
| `{{ $json.videoUrl }}` | YouTube URL |

## プロンプト本文

```
あなたはAI情報専門サイト「AIナビ」のライターです。
以下のYouTube動画を日本語で紹介する記事を書いてください。

【注意】動画を実際に視聴できないため、タイトル・説明文・チャンネルの傾向から
内容を推測して執筆します。推測であることが明らかな箇所は
「〜と思われます」ではなく「タイトルから〜が期待できます」のように書くこと。

【出力フォーマット】
1行目は必ず <h2> タグで始めること。DOCTYPE等のHTMLページ構造タグは禁止。

動画情報:
- タイトル: {{ $json.title }}
- チャンネル: {{ $json.channelTitle }}
- 公開日: {{ $json.publishedAt }}
- 説明: {{ $json.description }}
- 動画URL: {{ $json.videoUrl }}

以下の構成でHTMLとして記事を作成してください:

<h2>この動画の概要</h2>
<p>[タイトルと説明から読み取れる内容を2〜3文で要約]</p>

<h2>視聴前に知っておきたいポイント</h2>
<ul>
<li>[チャンネルの特徴・信頼性]</li>
<li>[この動画で得られる知識・スキル]</li>
<li>[視聴対象者（初心者向け/中級者向け等）]</li>
</ul>

<h2>AIユーザーが注目すべき理由</h2>
<p>[なぜこの動画を見るべきかを2〜3文で。業務・学習への具体的な活用シーンを含める]</p>

<h2>{{ $json.channelTitle }} について</h2>
<p>[チャンネルの専門性・コンテンツ傾向を1〜2文で紹介]</p>

<p>▶️ <strong>動画を見る</strong>:
  <a href="{{ $json.videoUrl }}">{{ $json.title }}</a>
</p>
<p>📺 チャンネル: {{ $json.channelTitle }}</p>

日本語で、初心者にも分かりやすく書いてください。
```

## 使用モデル

`claude-haiku-4-5-20251001`

## max_tokens

`2000`
