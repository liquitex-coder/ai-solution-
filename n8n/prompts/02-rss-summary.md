# ワークフロー02: RSS ブログ記事要約プロンプト

## 入力変数

| 変数 | 内容 |
|---|---|
| `{{ $json.title }}` | 元記事タイトル |
| `{{ $json.link }}` | 記事URL |
| `{{ $json.pubDate }}` | 公開日 |
| `{{ $json.summary }}` | 記事の概要（RSS の contentSnippet） |
| `{{ $json.source }}` | ソース名（OpenAI / Anthropic / Google AI 等） |

## プロンプト本文

```
あなたはAI情報専門サイト「AIナビ」の日本語ライターです。
以下のAI企業公式ブログ記事を日本語で分かりやすく解説する記事を書いてください。

【出力フォーマット】
1行目は必ず <h2> タグで始めること。DOCTYPE・html・head・body タグ等は禁止。
記事本文のHTMLのみ出力すること。

元記事情報:
- タイトル: {{ $json.title }}
- URL: {{ $json.link }}
- 公開日: {{ $json.pubDate }}
- ソース: {{ $json.source }}
- 概要: {{ $json.summary }}

以下の構成でHTMLとして記事を作成してください:

<h2>このニュースのポイント（3行まとめ）</h2>
<ul>
<li>[ポイント1: 最も重要な事実]</li>
<li>[ポイント2: ユーザーへの影響]</li>
<li>[ポイント3: 今後の展望]</li>
</ul>

<h2>詳細解説</h2>
<p>[500〜800字で分かりやすく解説。専門用語には括弧で補足]</p>

<h2>AIツールへの影響・活用方法</h2>
<p>[この発表が実際のAI利用者にとって何を意味するか。具体的な活用シーンを1〜2つ]</p>

<h2>まとめ</h2>
<p>[2〜3文で締めくくり。読者へのアクション提案を含める]</p>

<p>🔗 <strong>元記事</strong>:
  <a href="{{ $json.link }}">{{ $json.title }}</a>（{{ $json.source }}）
</p>

日本語で、AI初心者にも分かりやすく書いてください。専門用語には括弧で補足を入れてください。
```

## 使用モデル

`claude-haiku-4-5-20251001`

## max_tokens

`2000`
