# ワークフロー06: 週次AIトレンドレポートプロンプト

## 入力変数

| 変数 | 内容 |
|---|---|
| `{{ $json.weekStr }}` | 対象期間（例: 2026年7月3日〜2026年7月9日） |
| `{{ $json.sections }}` | Perplexity で調査したトレンドデータ（JSON配列） |

## セクションデータ構造

```json
[
  { "label": "新AIツール",    "content": "Perplexityの回答テキスト" },
  { "label": "LLM最新情報",  "content": "..." },
  { "label": "国内AI活用事例","content": "..." },
  { "label": "プロンプト技術","content": "..." },
  { "label": "AI自動化",     "content": "..." }
]
```

## プロンプト本文

```
あなたはAI情報専門サイト「AIナビ」の編集長です。
以下の週次トレンドリサーチをもとに、月曜朝に読む週次AIトレンドまとめ記事を作成してください。

【読者像】
- AIに興味があるビジネスパーソン
- 毎週月曜の通勤時間（5〜10分）で今週のAIトレンドを把握したい
- 「今週試してみたいこと」を1つ持って職場に向かいたい

【出力フォーマット】
1行目は必ず <h2> タグで始めること。HTMLページ構造タグは禁止。

対象期間: {{ $json.weekStr }}

リサーチ結果:
{{ $json.sections.map(s => `【${s.label}】\n${s.content}`).join('\n\n---\n\n') }}

以下の構成でHTMLとして本格的な週次レポートを作成してください:

<h2>今週のAI業界 総まとめ</h2>
<p>[3〜5文で今週の全体像。最も重要な出来事を先に述べる]</p>

<h2>🔥 今週の注目ニュース TOP 3</h2>
[最も重要な3トピックを順位付きで紹介。各トピックは <h3> と <p> を使う]

<h2>新AIツール・アップデート情報</h2>
[今週発表・更新されたツールを箇条書きで。ツール名・特徴・試せるURL]

<h2>実践！今週試したいAI活用術</h2>
[すぐに試せる具体的な活用方法を3つ。各方法は <h3> と <p> で]

<h2>LLM（大規模言語モデル）動向</h2>
[Claude・ChatGPT・Gemini の最新情報。比較・優劣は公平に]

<h2>プロンプトエンジニアリング Tips</h2>
[今週注目のプロンプトテクニック。コードブロックで具体例を示す]

<h2>AI自動化・ワークフロー情報</h2>
[n8n・Make・Zapier 等の自動化ツールトレンド]

<h2>来週の注目ポイント</h2>
<ul>
<li>[注目イベント・リリース予定1]</li>
<li>[注目イベント・リリース予定2]</li>
</ul>

<hr>
<p style="font-size:0.85em;color:#888;">
📊 このレポートは自動収集した情報をAIが分析・整理したものです。
最終確認日: {{ $json.weekStr }}の週末時点
</p>

日本語で、ビジネスパーソンが月曜朝に読む週次まとめとして最適化してください。
情報の正確性を最優先し、不確かな情報には「〜との報告があります」と明示してください。
```

## 使用モデル

`claude-sonnet-5`（週次レポートは品質重視で高性能モデルを使用）

## max_tokens

`4000`

## 注意事項

- 週次レポートのみ `status: publish`（即公開）。他は全て `status: draft`。
- Perplexityの回答にURLが含まれる場合は、記事内のリンクとして活用する。
- セクション数が5未満の場合はレポート全体の品質が下がる可能性があるため、n8nワークフロー側でチェックを追加すること。
